GECOM – Gestor para Consultorio Médico

Sistema de gestión desarrollado como proyecto académico, orientado a la administración de procesos básicos dentro de un consultorio médico. El proyecto permite gestionar usuarios, pacientes, citas y tareas administrativas mediante una estructura modular enfocada en la organización y facilidad de uso.

Módulos Principales.

Gestión de Usuarios

Permite el registro y administración de usuarios dentro del sistema.


Gestión de Pacientes

Módulo encargado del almacenamiento y control de información de pacientes.


Gestión de Citas

Permite crear, modificar y consultar citas médicas.


Gestión de Tareas

Ayuda a organizar actividades pendientes relacionadas con el consultorio.
